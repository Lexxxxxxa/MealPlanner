# MealPlanner

Інформаційна система планування харчування: каталог продуктів, рецепти з підрахунком калорій і БЖВ,
список покупок та підбір добового меню двома алгоритмами — жадібним і лінійним програмуванням
(двофазний симплекс-метод, реалізований без сторонніх бібліотек).

## Структура

| Проєкт | Призначення |
|---|---|
| `src/MealPlanner.Core` | Моделі, алгоритми (`GreedyPlanner`, `LpPlanner`, `SimplexSolver`), каталог продуктів (`Data/foods.csv`) |
| `src/MealPlanner.Api` | ASP.NET Core Web API (minimal API), EF Core + SQLite, Swagger |
| `src/MealPlanner.Benchmark` | Консольний експеримент: порівняння алгоритмів на наборах із 43–1000 продуктів |
| `tests/MealPlanner.Tests` | Модульні тести xUnit |

## Запуск

Потрібен .NET 8 SDK.

```bash
dotnet build
dotnet test
dotnet run --project src/MealPlanner.Api                      # Swagger: адреса з консолі, /swagger
dotnet run -c Release --project src/MealPlanner.Benchmark -- 10   # результати в results/benchmark.csv
```

## Математична постановка («задача про дієту»)

Змінні xᵢ ≥ 0 — маса продукту i (у сотнях грамів).

```
min  Σ pᵢ·xᵢ                              (вартість меню)
при  minₖ ≤ Σ aᵢₖ·xᵢ ≤ maxₖ,  k = ккал, білки, жири, вуглеводи
     xᵢ ≤ Mᵢ/100                         (максимальна порція)
```

Жадібний алгоритм додає порції по 25 г, обираючи продукт із найкращою оцінкою
«зважений закритий дефіцит / (вартість + штраф за енергію)».

## Примітки щодо даних

Поживна цінність і ціни в `foods.csv` — орієнтовні довідкові значення для навчального експерименту,
а не офіційні дані. Для наборів понад 43 продукти використовується детермінована генерація
варіацій базових продуктів (`FoodCatalog.Generate`), тому результати масштабування — це
результати на синтетичних даних.
